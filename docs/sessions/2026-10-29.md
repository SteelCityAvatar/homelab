## Installer USB

- **ISO verified:** `Get-FileHash` SHA256 `4e88fe41…3ef2c6c` matches Proxmox's
  official `SHA256SUMS` exactly (compared programmatically, not by eye).
- **First stick (Lexar 32GB) failed.** Rufus 4.15 reported "Write error". Its log:
  - `Windows VDS is unavailable` / `Could not delete partition(s)` — the stick's old
    partitions stayed mounted.
  - `Write error at sector 0: Incorrect function` — Windows blocks raw writes to a
    disk with a mounted volume.
  - Wiping it with `Clear-Disk` then hung Windows' storage stack (VDS stopped
    responding); a reboot recovered it, other disks Online/Healthy. Three failures
    → the stick is **retired**.
- **A new stick wrote cleanly.**
- Lesson: run disk queries on Windows inside a job with a timeout (`Start-Job` +
  `Wait-Job -Timeout`) so a stuck USB device can't freeze the session.

## Command log — desktop (admin PowerShell)

1. **List disks, look for the ISO** (read-only)
   ```powershell
   Get-Disk | Format-Table Number, FriendlyName, BusType, @{n='SizeGB';e={[math]::Round($_.Size/1GB,1)}}, PartitionStyle, OperationalStatus -AutoSize
   ```
   → Disk 0 WD 8TB (SATA), 1 9100 Pro (NVMe), 2 Seagate Backup+ (USB), 3 Lexar 29.8GB (USB).

2. **Hash the ISO** (read-only)
   ```powershell
   Get-FileHash "D:\Sftwr\proxmox-ve_9.2-1.iso" -Algorithm SHA256 | Format-List Hash
   ```
   → `4E88FE41…3EF2C6C`.

3. **Compare against the official SHA256SUMS** (read-only)
   ```powershell
   $line = Select-String -Path "<saved SHA256SUMS>" -Pattern 'proxmox-ve_9\.2-1\.iso' | Select-Object -First 1
   $official = ($line.Line -split '\s+')[0]
   $official -eq '4E88FE416DF9B527624A175F24C9AA07C714D3332AFB1EE3DBF3879573EF2C6C'
   ```
   → `True`.

4. **Wipe the Lexar — destructive, disk number confirmed manually first.** Guarded so
   it aborts if disk 3 isn't the expected device:
   ```powershell
   $d = Get-Disk -Number 3
   if ($d.FriendlyName -eq 'Lexar USB Flash Drive' -and $d.BusType -eq 'USB' -and [math]::Round($d.Size/1GB,1) -eq 29.8) {
     Clear-Disk -Number 3 -RemoveData -RemoveOEM -Confirm:$false
   } else { "ABORT: disk 3 is now '$($d.FriendlyName)' ($($d.BusType)) - not wiping" }
   ```
   → **Hung** (storage stack froze). Stick unplugged, PC rebooted.

5. **Post-reboot health check, with a 20 s timeout** (read-only)
   ```powershell
   $j = Start-Job { Get-Disk | Select-Object Number, FriendlyName, BusType, OperationalStatus, HealthStatus }
   if (Wait-Job $j -Timeout 20) { Receive-Job $j | Format-Table -AutoSize } else { "TIMEOUT"; Stop-Job $j }
   Remove-Job $j -Force
   ```
   → 9100 Pro and WD 8TB Online/Healthy.
