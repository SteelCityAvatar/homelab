## "2 users" with one login

`uptime` reported 2 users while `who` listed one SSH login. Cause: `uptime` counts
every systemd-logind session of class `user`, including ones with no terminal;
`who` lists only sessions with a terminal.

- Session 375: the current SSH login.
- Session 226: class `manager-early`, the per-user service manager. Not counted.
- Session 225: the SSH login from 2026-11-11, state `closing`. Its connection dropped
  on 2026-11-12 02:03 (`Read error from remote host … No route to host`), but the
  session stays open because `tmux new -s nvidia` and its shell are still running in
  it. This is the tmux session used for the driver install, surviving the dropped
  connection as intended.

**Lesson:** a detached tmux session keeps its original login session alive, so
`uptime`'s user count can exceed what `who` shows. `loginctl list-sessions` and
`loginctl session-status <id>` show what is holding a session open.

⚠️ Not confirmed whether the idle tmux session was closed afterwards
(`tmux kill-session -t nvidia`). Leaving it is harmless.
