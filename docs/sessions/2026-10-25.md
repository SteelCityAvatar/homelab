## PSU test (2026-10-25)

**Voltages — Corsair TX750M, light load (board + iGPU only):**

| Rail | Reading | Spec (±5%) | Result |
|---|---|---|---|
| 12V | 11.97V | 11.40–12.60 | Pass |
| 5V | 5.08V | 4.75–5.25 | Pass |
| 3.3V | 3.35V | 3.14–3.47 | Pass |

The PSU is healthy **at light load**. An aging PSU usually shows weakness under
heavy load, so **re-test with the GPU working before Phase 2**.

**Cables:**

- **Bagged modular SATA cables: two tested, both BAD.** 3.3V in the center where 5V
  belongs, 5V at the far end, and 12V at the hook end where 3.3V belongs. They would
  have killed a drive. **Do not use. Label them.**
- **Factory-attached SATA cable: correct.** Now powering the IronWolfs.
- **Modular CPU 8-pin from the same bag: works** (board POSTs and boots), so that bag
  is mixed or partial.
- **Modular PCIe cables: untested.** Use only the factory-attached PCIe cables. Test
  any modular PCIe cable before it goes near a GPU.

**Incidents — both came through fine:**

- CPU 8-pin pulled while the system was running → board shut off. Re-seated; boots normally.
- GPU seated with the rocker on (system in standby) → card detected afterwards.

**Open:** a PSU noise was heard but not characterized. `bom.md` #23 lists coil
whine as a replace trigger. Listen with a clear head. Crackling, popping,
sizzling, clicking or a burning smell = switch off immediately.
