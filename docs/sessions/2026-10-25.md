## PSU test (2026-10-25)

**Voltages — Corsair TX750M, light load (board + iGPU only):**

| Rail | Reading | Spec (±5%) | Result |
|---|---|---|---|
| 12V | 11.97V | 11.40–12.60 | Pass |
| 5V | 5.08V | 4.75–5.25 | Pass |
| 3.3V | 3.35V | 3.14–3.47 | Pass |

Healthy **at light load**. An aging PSU usually shows weakness under heavy load, so
**re-test with the GPU working before Phase 2**.

**Cables:**

- **Bagged modular SATA cables: two tested, both BAD.** 3.3V in the center where 5V
  belongs, 5V at the far end, 12V at the key end where 3.3V belongs — a different
  PSU's pinout. They would have killed a drive. **Labeled; out of the build.**
- **Factory-attached SATA cable: correct.** Powers the IronWolfs.
- **Modular CPU 8-pin from the same bag: works** (board POSTs and boots), so the bag
  is mixed.
- **Modular PCIe cables: untested.** Factory-attached PCIe cables only until tested.

Procedure: `docs/runbooks/verify-modular-psu-cables.md`.

**Events — both recovered without damage:**

- CPU 8-pin disconnected under power → board shut off; re-seated, boots normally.
- GPU seated with the PSU on in standby → card detected afterwards.

**Open:** a PSU noise was heard but not characterized. `bom.md` #23 lists coil
whine as a replace trigger. Crackling, popping, sizzling, clicking or a burning
smell = switch off immediately.

## Storage notes

- Windows Disk Management initialized the IronWolfs as GPT. Harmless — ZFS pool
  creation wipes it.
- Avoid SATA5/6: they're disabled if M2_2 is ever populated.
- The desktop's 8TB HDD holds most data today as a **single copy**. It stays as the
  off-server copy until a Vault backup exists (`bom.md` #23 condition (a)).
- Keep vs. return the IronWolfs: open. The mirror gives ~3TB comfortable usable —
  enough only if the irreplaceable portion (photos, documents, code) fits.
