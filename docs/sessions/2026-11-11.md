## Notes

- DKMS built the module for 7.0.14-26-pve only. The 7.0.2-6 fallback kernel in GRUB
  would boot without the NVIDIA module (fine for recovery, no GPU).
- **Kernel module flavor: open** (`license: Dual MIT/GPL`). The open modules run part
  of the driver on the GPU's own GPU System Processor (GSP), using the firmware
  `/lib/firmware/nvidia/595.104.02/gsp_tu10x.bin` (TU10x = Turing).
- **Install record rewritten cleanly:** `/var/lib/nvidia/log` starts with the
  version header and file entries, so future upgrades/uninstalls can read it.
- ⚠️ Not yet checked: that `/dev/nvidia-uvm` exists after a reboot (needed for the
  LXC).

## Decisions

- **The PSU load test runs inside the model-serving LXC, before Ollama**, not on the
  host. Generating GPU load needs CUDA libraries, which stay off the hypervisor.
  Creating the container puts no load on the GPU, so the gate now blocks Ollama
  (always-on GPU work) instead of the container.
